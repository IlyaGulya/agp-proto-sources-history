# AGP generated protobuf sources

Generated protobuf Java sources extracted from Android Gradle Plugin source artifacts.
Every AGP release is stored as a commit and tagged `agp-<version>`.
The repository is consumed as the `generated/protos` submodule of `agp-sources-history`.

GitHub Actions checks Google Maven every day at 03:07 UTC and imports alpha, beta, release
candidate, and stable builds. The main sources repository follows at 04:17 UTC and records the
matching protobuf tag as its submodule pointer.
